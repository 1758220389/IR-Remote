# V1 手势数据分析

在仓库根目录运行 .\ml\.venv\Scripts\python.exe ml/analysis/build_v1.py。生成文件在 ml/data/v1。清单内的源路径相对于 ml，原件只读。manifest.csv 记录来源、标签、会话、质量、排除原因及 CSV SHA-256。features.csv 每窗一行。bias.csv 记录静置来源批次与零偏，session_summary.csv 按会话、类别汇总时长、跨度、点数及关键特征。

## 730 ms / 72 点

会话 pilot-20261117-185831-966 的 CCW #8，首末时间戳 16813 和 17523 ms。跨度 710 ms，71 个相邻间隔全为 10 ms。730 ms 是固件从消抖确认按下到确认松开的时长。固件分别记录按键时刻和环形缓冲起点，采样时钟与按键边缘可以错开。现有记录无法确定是否在窗边缘少收一点。原质量规则要求 |点数 × 10 ms − 按键时长| < 10 ms，此窗等于 10 ms，因此保留原判定及排除状态。

## 零偏和特征

每个引导会话用该会话 5 个有效静置窗口的全部采样点求三轴均值，再从陀螺仪数据分别减去。四个会话的 X/Y/Z 零偏范围分别为 +6.16 至 +7.04、+1.13 至 +1.37、−1.26 至 −1.03 °/s。X 轴跨会话变化约 0.88 °/s。手动补充集使用四个引导会话按点合并的静置均值 (+6.526, +1.259, −1.162) °/s，标记 pooled_exploratory，仅用于探索。

独立模块 [features.py](features.py) 保留原时间戳和可变窗长。积分按首至末样本的相邻时间差做梯形累计。加速度保留原始重力成分。无滤波、重采样或姿态补偿。

| 特征列 | 计算 | 单位 |
| --- | --- | --- |
| gyro_integral_* | 校正角速度有符号积分 | ° |
| gyro_peak_abs_* | 校正角速度绝对峰值 | °/s |
| gyro_abs_integral_* | 校正角速度绝对值积分 | ° |
| gyro_energy_* | 校正角速度平方积分，作为运动强度 | °²/s |
| gyro_z_energy_ratio | Z 强度占三轴强度之和的比例，总和为零时记 0 | 无量纲 |
| duration_ms / sample_span_ms / sample_count | 固件按键时长 / 首末采样跨度 / 实际点数 | ms / ms / 点 |
| accel_range_* | 各轴峰峰差 | g |
| accel_total_variation_* | 各轴相邻差的绝对值之和 | g |
| accel_norm_range_g | 三轴加速度向量模长的峰峰差 | g |

50 个 CW 的 Z 积分全为负，40 个 CCW 全为正。两轮新增引导的 CCW 最小积分分别为 +39.58° 和 +35.11°。全部引导中，最弱 CCW +4.22° 与最大正向 NONE +3.98° 仅差约 0.24°。Z 峰值在 CCW 与非目标 NONE 之间已经重叠，能量占比在三类之间均重叠。

引导会话的 CW、CCW 中位幅度分别约 29–44°、30–49°。以 Z 峰值作为速度代理，它与 Z 绝对积分在 CW、CCW 内的 Spearman 相关分别为 0.78 和 0.52。数据没有逐窗标注起始倾角与速度，无法分离两者的影响。Z 能量和峰值相关约 0.94，窗长与采样跨度相关约 0.999。优先采用 Z 有符号积分，峰值、能量占比及加速度变化作为候选辅助特征。

## 下一阶段实验

- 主集做四折留一会话验证，每折三个会话训练、一个会话验证。完整动作始终只对应一行。CW-only 补充集可单独报告方向或召回表现。
- 每折从训练会话静置记录计算统一零偏，重新提取该折训练与验证窗口的特征。训练折内确定标准化、特征和阈值。当前探索表用过各会话自身的静置数据，不直接作为验证输入。
- 先做基于 Z 有符号积分、带 NONE 死区的非对称阈值基准，再比较浅层决策树和逻辑回归。在训练会话内做分组参数选择，逐折报告 NONE 误触、CW/CCW 漏检和反向判定。重点检查弱幅 CCW 与动作型 NONE。

本轮未拟合分类器，未修改采集固件、平台或正式遥控器代码。
