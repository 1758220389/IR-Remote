# 正式遥控器手势整合与历史影子验证

当前已启用正式控制，见下节。本文后续影子阶段记录仅代表当时状态；源码的 GESTURE_SHADOW、GestureShadow 和监视工具名称为历史命名。

## 当前正式控制（2026-11-18）

正式固件已烧录，应用区及末尾 16 KiB 配置区均逐字节读回验证。用户实体测试确认 CW 能使空调升温、CCW 能使空调降温；NONE 和异常窗口不产生手势事件，原五个实体按键正常。有效事件经 on_button → Ui_Button 复用原 BUTTON1/2 的温控、红外发送、状态保存及 OLED 刷新逻辑，仅正常页动态空调配置允许派发。诊断 proposed_key 表示派发键，并不保证红外发送成功。

按住 BT6 旋腕后松开；少于 150 ms、达到 1.5 s 上限的截断窗、采样时序异常、饱和或传感器故障均拒绝。100 Hz 可变窗流式累计 Z 轴角速度梯形积分，使用冻结 V1.0.0 三分类逻辑回归，无需 PC。接线见下表；MPU6500 VCC=3.3 V、GND/AD0 接地，SCL/SDA 上拉至 3.3 V。

正式工程为 code/IR_Remote.uvprojx，使用 ARMCC5 Rebuild；不得移除当前启用的 GESTURE_SHADOW 定义。应用限定 0x08000000–0x0800BFFF（48 KiB），配置为 0x0800C000–0x0800FFFF（16 KiB，两银行）。下载前备份完整 Flash 与配置区到本地忽略目录，只按应用扇区擦除，读回应用并确认配置区与备份一致后运行，禁止全片擦除。正式板 PA10 属于 BT5，不连接独立采集板的 UART TXD。

正式控制构建历史记录：Code 29178 + RO 6334 + RW 200 = Flash 35712 B，RW 200 + ZI 17536 = RAM 17736 B，0 错误、0 警告。这是最终整合工程占用，独立识别报告中的 2288 B / 64 B 增量不适用于此工程。

识别灵敏度仍有优化空间，V1.0.0 模型冻结；大规模实体准确率、完整红外学习与配置持久化整机回归、操作重叠时序与长期稳定性仍待验证。98.33% 是四轮留一会话交叉验证，不能视为真实整机准确率。

## 历史影子阶段

基线为正式主线 cb85e1f。本地功能分支通过快进更新到该版本。独立采集工程、历史样本和模型系数保留。

## 采样与监测

按下 BT6 开始、松开结束，20 ms 防抖，150 ms 下限，1.5 s 上限。前台每 10 ms 至多执行一次传感器读，每次 14 字节，配置分步完成。沿用 V1.0.0 的零偏、梯形积分和仿射评分。通过流式累计角度梯形和及质量标志，避免再分配 150 点数组。

OLED 全屏刷写、Flash 擦写／提交会同步占用主循环；学习解码、红外中断、按键引起的页面刷新也可能改变采样间隔。影子前台在原任务之后运行，不补写虚假采样点。记录实测最小和最大间隔及跳过周期；毫秒间隔不是 10 ms、实测间隔超出 9–11 ms、窗口端点时差或点数不合法时拒绝。红外收发期间的实际影响需分别上板测量。I²C 每个线释放等待最多 100 µs，传感器失败退出并分时重试；无需 STM32 定时器、DMA 或额外中断。

用同次构建生成的 IR_Remote.map，双击 [Start-Shadow.cmd](../Start-Shadow.cmd)。CPU 持续运行，窗口通过 SWD 只读观察 MCU 标签、拟议键、分数、采样间隔和拒绝原因。PC 每读到完整窗口就立即在 ml/data/shadow 追加并刷盘，连续轮询同一窗口不重复写入。完成后在下一次按键前选定实际动作，点「补标注实际动作」。标注与窗口通过 record_id 关联，断线后仍可在当前窗口补标最后一条已保存的记录。掉电前尚未被 PC 完整读到的结果无法从 RAM 恢复。窗口不发送任何实际控制命令。

## 实板验收顺序

1. 先保存完整 64 KiB Flash。仅按扇区烧录应用并停核读回确认末尾 16 KiB 未被擦写，再运行应用。
2. 正常页做 CW、CCW、静置、非目标动作各至少一次，逐个标注。比较真实标签与 MCU 输出，确认无手势红外及温度变化。
3. 保持同样方法，分别在 OLED 页面变化、实体按键使用、红外接收／发送及保存配置附近观察拒绝原因和实际间隔。
4. 检查五键与 OLED、用真实遥控器完成学习并验证原实体键能发送，以及冷启动原配置可以读回。需要保存时优先使用空配置槽，避免覆盖用户数据。
5. 复核影子记录、资源余量及原功能回归结果，等待确认才进入最终控制验收。

本轮没有开启手势控制。独立识别的历史回放用共享 C 模块重新运行后仍为 128 条一致、2 条按截断规则拒绝。
- 基线链接占用 Flash 31,908 B、RAM 17,584 B。影子版链接占用 Flash 35,684 B、RAM 17,736 B，新增 3,776 B / 152 B，剩余 13,468 B / 2,744 B（栈和堆已计入）。ARMCC5 全量编译 0 错误、0 警告。
- 实板仅按扇区下载。备份路径为 ml/data/flash-backups/20261118-000438-shadow。停核读回应用及末尾 16 KiB 均与相应源逐字节一致。启动后 SWD 实读 WHO_AM_I=0x70、传感器就绪，原配置加载成功，初始红外收发计数均为 0。
